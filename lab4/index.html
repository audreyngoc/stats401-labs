Lab 4: Cleaning Web Data for Visualization

Dataset Description

This project uses the Customer Support on Twitter dataset. The dataset contains Twitter conversations between customers and company support accounts.

Each record contains information including a tweet ID, author ID, whether the tweet was inbound, the creation time, tweet text, and links connecting customer tweets with company responses.

Analysis dataset: The original dataset contains more than 2.8 million tweets. Customer tweets were linked to company responses using response_tweet_id. The 10 companies with the largest numbers of linked customer tweets were selected, and 500 tweets were randomly sampled from each company, producing 5,000 tweets for analysis.

Data Source

The dataset was obtained from Kaggle: Customer Support on Twitter .

The original dataset can be accessed through the Kaggle dataset page: https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter. Because the raw dataset is large and has redistribution restrictions, the original CSV is not included in this GitHub repository.

To reproduce the analysis, follow these steps:

  1. Download the dataset from Kaggle.
  2. Extract twcs.csv.
  3. Place the file in data/raw/twcs.csv.
  4. Run lab4/clean_tweets.py to clean the raw data and create the analysis dataset.
  5. Run lab4/sentiment.py to apply the RoBERTa sentiment model to every tweet.

The dataset contains Twitter customer-support conversations involving customers and company support accounts. The resulting cleaned dataset is used to create the sentiment visualization.

Data Cleaning

The raw dataset was inspected for missing values, duplicate records, duplicate tweet IDs, empty tweet text, invalid dates, and incorrect data types.

Tweet IDs and response IDs were converted to numeric types, timestamps were parsed using the original Twitter date format, and tweet text was cleaned by collapsing unnecessary whitespace and removing leading and trailing spaces.

Customer tweets were identified using the inbound field. Customer tweets were then matched to company responses through the response tweet ID. Tweets that could not be directly linked to a company were excluded from the company-level analysis.

Sentiment Analysis

Sentiment was generated for every tweet in the analysis dataset using the CardiffNLP Twitter RoBERTa sentiment model .

Before classification, user mentions were replaced with @user and URLs were replaced with http to preserve the general structure of Twitter language while reducing unnecessary variation.

The model produces probabilities for negative, neutral, and positive sentiment. The sentiment label is the category with the highest predicted probability.

Sentiment score: The continuous sentiment score is calculated as positive probability minus negative probability. A higher score indicates more positive predicted sentiment, while a lower score indicates more negative predicted sentiment.

These sentiment labels are model-generated predictions rather than ground-truth labels. They may be affected by sarcasm, irony, slang, ambiguity, and domain-specific language.

Customer Sentiment Across Companies

The visualization compares sentiment distributions across companies using a 100% stacked horizontal bar chart. The visualization compares the distribution of customer sentiment across the 10 selected companies using a 100% stacked horizontal bar chart. Each horizontal bar represents 100% of the sampled customer tweets for one company.

How to read the visualization: The length of each segment represents the percentage of tweets classified as negative, neutral, or positive. Companies are ordered from highest to lowest average sentiment score.

Analysis

The visualization shows substantial differences in customer sentiment across the 10 companies. Southwest Airlines has the highest average sentiment score and the largest positive share, with 41.6% of sampled customer tweets classified as positive. It is also the only company where positive tweets make up a larger share than negative tweets. In contrast, Uber has the lowest average sentiment score, with 68.0% of tweets classified as negative and only 3.0% as positive. Apple and Comcast also show relatively high proportions of negative sentiment. Across the 5,000 sampled customer tweets, negative sentiment accounts for 53.2%, compared with 30.7% neutral and 16.1% positive sentiment. Overall, negative sentiment is the largest category for most companies, while the average sentiment score provides a continuous measure for comparing their relative sentiment. The differences suggest that customer experiences expressed through support conversations vary considerably across companies.
