STATS 401: Data Acquisition and Visualization

Lab 5: Interactive Network Visualization

Dataset Description

This project uses the provided synthetic urban transit network dataset. The network contains 50 stations and 50 direct transit connections across five districts: Central, North, South, East, and West.

The station dataset contains the station ID, station name, district, daily passenger volume, and station type. Station types include Local, Transfer, and Terminal.

The route dataset contains pairs of connected stations, travel time in minutes, and route type. Route types include Metro, Express, and Shuttle. The network is treated as undirected, so a connection between two stations represents a direct connection in either direction.

Node-Link Visualization

The force-directed network below represents the 50 stations and their direct transit connections.

Node-Link Design Description

The node-link visualization represents the 50-station transit network using an interactive force-directed layout. Each station is represented as a node and each direct connection as a link. District is encoded by node color, allowing users to distinguish the five geographic groups. Station type is encoded by node shape, distinguishing Local, Transfer, and Terminal stations. Daily passenger volume is encoded by node size, making stations with higher passenger volumes visually prominent. For links, travel time is encoded by thickness, with thicker links representing longer direct travel times, while route type is encoded by line pattern to distinguish Metro, Express, and Shuttle services.

These encodings use different visual channels to distinguish categorical and quantitative attributes. Color and shape support categorical identification, while size represents the quantitative passenger-volume variable. For connections, line thickness represents quantitative travel time, and line pattern distinguishes route categories without adding another color scale. This makes heavily used stations, different station functions, and longer connections easier to identify within the network topology.

The visualization also supports dragging, zooming, hover highlighting, and tooltips. Dragging allows users to reposition nodes and inspect relationships from different spatial arrangements. Hovering emphasizes a selected station and its direct connections, reducing visual clutter in the dense network. Tooltips provide detailed station and connection information that cannot be encoded directly without making the visualization harder to read.

Adjacency Matrix

The adjacency matrix represents the same 50-station network. Rows and columns correspond to stations, and each cell represents the relationship between a pair of stations. A filled cell indicates a direct transit connection.

Matrix Design Description

The matrix represents direct station connections through individual cells, with the same station list used for both rows and columns. Cell opacity represents travel time, so darker cells indicate longer direct connections. Cell patterns distinguish route types, allowing Metro, Express, and Shuttle connections to be inspected without relying on the node-link layout.

The row and column ordering is district → station type → passenger volume. This ordering groups stations with similar attributes together and creates visible blocks of connections. District is also indicated by the color of station labels, while station markers communicate station type and passenger-volume categories. The matrix is therefore particularly useful for identifying connection patterns across groups of stations and for locating longer direct connections without relying on spatial distance in the force-directed layout.

Network Questions and Findings

The two visualizations support different aspects of network exploration. The node-link view is most useful for inspecting individual stations, their neighbors, station attributes, and local connectivity. The adjacency matrix is particularly useful for comparing connection patterns across groups of stations and for locating specific station pairs.

  1. Which stations appear central in the network?

    Answerability: Partially answered.

    Most useful visualization: Node-link. The links surrounding each station make local connectivity visible, while hover highlighting helps identify a station's immediate neighbors and connected portion of the network.

    Finding: Stations such as 7, 18, 31, and 34 appear relatively important in the topology because they connect multiple nearby parts of the network. Other stations, including 23, 29, and 38, also have several direct connections. In contrast, Stations 42, 46, and 49 appear isolated in the visualization and therefore do not appear central. No single station forms a clearly dominant hub.

    Note: This visualization supports observations about visible connectivity, but it does not calculate a formal centrality measure. The force-directed positions also represent network topology rather than geographic location.

  2. Which districts are strongly connected to one another?

    Answerability: Well answered.

    Most useful visualization: Adjacency matrix. The row and column ordering by district creates visible blocks, making connections between district pairs easier to compare.

    Finding: The densest cross-district block is between East and South, with 11 direct connections. Central–North and East–West also show relatively strong connections, with 9 connections each. Central–West and North–South each have 8 connections.

    Note: The matrix is especially effective here because grouping stations by district makes repeated connection patterns visible as blocks.

  3. Where are transfer or terminal stations located in the topology?

    Answerability: Well answered.

    Most useful visualization: Node-link, with the matrix providing supporting information. Station type is encoded by shape: circles represent Local stations, diamonds represent Transfer stations, and squares represent Terminal stations.

    Finding: Transfer stations such as 23, 29, and 38 appear at relatively well-connected points in the topology because each has several direct links. Terminal stations show more variation: 25, 31, and 34 are integrated into the network with multiple connections, whereas 43, 46, and 49 appear more peripheral. Thus, transfer and terminal stations occur at different topological positions rather than forming one distinct cluster.

    Note: The force-directed layout represents network topology, not geographic location.

  4. Which stations have high passenger volume?

    Answerability: Well answered.

    Most useful visualization: Both, although the node-link view makes the differences easiest to see. Passenger volume is encoded by node size in the node-link view and by marker size along the matrix axes.

    Finding: Stations such as 46, 47, 48, 49, and 50 appear among the largest station symbols, indicating relatively high passenger volume. The size encoding makes high-volume stations visually prominent without requiring users to read individual values.

    Note: The visualization is effective for identifying relative passenger volume. Tooltips can provide the exact value when needed.

  5. Where are the longest direct travel-time connections?

    Answerability: Well answered.

    Most useful visualization: Both. In the node-link view, thicker links represent longer travel times. In the matrix, darker cells represent longer connections.

    Finding: The particularly thick link between Station 7 and Station 31 stands out as the longest direct connection at 16 minutes and is encoded as an Express route. Other prominent long connections include Station 18–Station 34 (15 minutes) and Station 29–Station 50 (14 minutes).

    Note: The node-link view makes the longest connections visually prominent, while the matrix allows the corresponding station pair to be located at the intersection of its row and column.

  6. Are particular route types concentrated in particular parts of the network?

    Answerability: Partially answered.

    Most useful visualization: Both, with the adjacency matrix particularly useful for comparing district pairs. Route type is encoded by line pattern in the node-link view and by cell pattern in the matrix.

    Finding: The matrix shows that Metro, Express, and Shuttle patterns occur across multiple district-pair blocks rather than being confined to one part of the network. The East–South block, which contains the largest number of connections, contains multiple route types rather than being dominated by one pattern. Some local differences are visible, but there is no strong overall concentration of a single route type.

    Note: The visualization supports a qualitative comparison of route-type distribution, but it does not provide a formal statistical test of concentration.
