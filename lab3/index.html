Lab 3: Web Data Acquisition

Dataset Description

This dataset contains product records collected from the Biti's Vietnam online store. Each row represents one unique product listed in the website's public product catalog.

The dataset includes product images, product identifiers (product IDs), product names, prices, brands/vendors, categories, availability (whether the product is still sold), variants, and the product URL from which each product was discovered.

Acquisition method: REST API/JSON acquisition using Python's requests library. The script requests Biti's public products.json endpoint, parses the returned JSON data, and saves the resulting records as a CSV file.

Data Source

Biti's Vietnam online store: https://bitis.com.vn/

The data is acquired from Biti's publicly accessible product JSON endpoint. The endpoint supports pagination, allowing the Python script to request multiple pages automatically.

The script checks Biti's robots.txt before making requests and uses a one-second delay between repeated requests to avoid excessive server load.

Number of Records

The Python acquisition script is configured to collect at least 1,000 unique product records.

Products appearing in multiple collections are deduplicated using their product identifier or product URL before the final CSV file is saved.
